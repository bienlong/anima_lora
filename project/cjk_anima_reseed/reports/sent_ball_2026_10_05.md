# sent_ball: a warm ball on preview51's kana rows, dialogue lines the main data (2026-10-05)

From `sent_plan.md` (user, 10-05): the 163 kana rows warm at
`seed_fixed_1005_stick080` (the rows preview51 ships), their mean held, the
rows less it trained on items 70 % dialogue lines (`sent_34` / `sent_22`).
Read on the dialogue ruler paired against those same rows.

- **The arm reads worse than the rows it started from.** Against preview51 on
  the 96 strings: exact 1 / 8 (p 0.039), contained 1 / 9 (p 0.021), ≤ 2 edits
  4 / 7 (p 0.55), cer +0.05 (p 1.0). The loss is the short bin (exact 8 → 2);
  mid and long do not move (long ≤ 2 edits 0 / 32 on both). The page ties
  (en_cos, en_tok_out, flat white).
- **The dialogue data did not buy the long strings.** 83 % of the kana
  occurrences sat in 8–14 cell lines; no long string comes within 2 edits,
  and cer on long is 0.742 vs 0.754.
- **On long strings the arm letters less text, not more.** Page-read glyphs
  23 vs 35 (sent_ball fewer on 25 / 32 images). On short strings it letters a
  little more (16.5 vs 14, 17 / 9, p 0.24 — not a finding; the first sheet
  looked like dialogue blocks leaking into short prompts, the count does not
  carry it).
- **The rows turned sideways, at the same length, not out from the tip** (§ 3).
  Each spike (row less the held mean) turned to cos 0.77 of its start with
  its length kept (ratio 1.00); the change is 0.68 of a spike long and
  points partly back along it (cos −0.33). Identity holds by nearest
  neighbour (163 / 163). The length moved with data frequency (Spearman
  0.94): the dialogue kana grew (だ よ が で +20–25 %), the rare ones shrank
  and turned most (ぺ ぷ ヂ む ヅ −30–40 %, ヌ to cos 0.28).

## 3. Where the rows went

Effective units (`raw × row_scale`), the 163 trained rows; stick = their mean
(held), spike = a row less it, Δ = end spike − start spike. Median (p10–p90).

| | |
|---|---|
| row cos start / end | 0.827 (0.761–0.871) |
| spike cos start / end | 0.769 (0.696–0.815) |
| \|spike\| start → end | 204 → 196 (157–261) |
| \|end\| / \|start\| | 1.00 (0.80–1.17) |
| \|Δ\| / \|start spike\| | 0.68 (0.62–0.79) |
| end spike along start (coef) | 0.78 (0.58–0.91) |
| end spike ⊥ start / \|start\| | 0.62 (0.54–0.75) |
| cos(Δ, start spike) | −0.33 (−0.61 – −0.12) |
| cos(Δ, stick) | 0.04 |

- **A turn, not an extension.** Δ does not continue the spike (that would be
  cos(Δ, start) near +1 and a ratio over 1): it takes back a fifth of the old
  spike and adds a perpendicular part 0.62 as long, the length kept.
- **Each row its own direction.** Δ's top singular direction holds 5.9 % of
  its energy, top 5 15 % (the start spikes: 6.2 / 17.6 %) — no shared
  "dialogue" direction. 36 % of Δ lies in the span of the start spikes
  (chance 16 %): partly toward other glyphs' spikes, mostly new.
- **Identity by neighbour holds**: every end row is nearest its own start
  (163 / 163; spikes 162 / 163, the next start spike at cos 0.27).
- **Length follows the data.** Spearman 0.94 between a glyph's occurrences in
  `train.jsonl` and its length ratio (0.42 with its spike cos). Hiragana
  grew (ratio 1.12), katakana shrank (0.96). Grew most: だ よ が で れ ま
  る た し そ (1.19–1.25). Shrank most: ぺ ぷ ヂ む ヅ ぴ ぉ ヌ ヲ ユ
  (0.61–0.72). Turned most: ヌ 0.28, む 0.44, ぷ 0.52, ヲ 0.57.
- **The held mean pushes the rare rows.** The 30 rarest rows' Δ sit at cos
  0.20 to minus the sum of the 30 most frequent rows' Δ (the frequent ones at
  −0.37 to it): putting the mean back after each step moves every row
  against what the frequent rows learned. AdamW runs at weight decay 0, so
  the shrink is not decay.
